# Design changes from original SFC

This folder records deliberate differences between this single-player browser game and the original Starfleet Commander experience. Each note separates what the reference shows from the behavior chosen for this game, explains the intent, and lists any open decisions so future work does not mistake an early choice for a settled rule.

## Change notes

- [Galaxy slots and orbital positions](galaxy-design.md) — use eight colonizable planetary berths and seven orbital positions in each 15-slot system.

## Adding a change note

Create one Markdown file per design area. Include the original-game reference or observation, the behavior chosen for this game, the reason for the change, and decisions that remain open. Keep implementation status and source links close to the relevant details.
